Copilot Pulse 1.9.8 · Windows 安装版

安装：双击 CopilotPulse-Setup-1.9.8-x64.exe，按提示完成安装。
支持 Windows 10（1809 或更新）/11 x64。默认按当前用户安装，不需要管理员权限。
自带 .NET 运行环境；若电脑缺少 WebView2，安装程序会使用微软官方引导程序联网安装。
桌面快捷方式可在安装过程中选择，开始菜单中也能打开组件。

登录：默认尝试当前 Windows 主账号 SSO。企业账号提示来自本机，不内置任何人的账号。
第一次使用若提示连接，请点击“连接 Microsoft 账户”，在微软官方页面选择自己的企业账号，按要求完成 MFA。
本机保存的组件登录会话可能继续使用上次登录的账号。多账号、个人 Windows 账号或公司访问策略可能要求手动登录。
每位使用者都需要有 https://copilot.github.microsoft.com/ 的访问权限，以及可访问内部页面的网络环境。
系统浏览器可以打开原页面；组件的数据采集通过独立 WebView2 会话完成。

历史：今天按本机 00:00 开始；配额月份按 UTC 00:00 划分，中国时区每月 1 日 08:00 重置。使用“月份 ▾”选择已有月份。

使用：默认每 60 秒刷新。菜单中可以换肤、选择完整/紧凑/迷你模式，查看历史趋势。
收起到托盘后仍可刷新；退出期间不采集，重启后继续追加历史。

安装位置：%LOCALAPPDATA%\Programs\CopilotPulse
用量、设置及历史：%USERPROFILE%\Documents\Codex\CopilotPulse-data
本机登录配置：%LOCALAPPDATA%\CopilotPulse\WebView2
升级前请从托盘菜单退出组件。安装新版和卸载默认保留上述个人数据。
卸载入口：Windows 设置 → 应用 → 已安装的应用 → Copilot Pulse。

分享：只需发送安装 EXE；本文件可一起发给对方。
安装包不包含个人历史、用量、Cookie、密码或 API Key。美术资源已嵌入，运行不需要图像服务配置。
此安装包尚未使用企业代码签名证书签名；若公司应用策略要求签名，需要由公司认可的渠道签名或分发。
