# 文档截图说明

这组截图用于 Copilot Pulse 1.9.6 的介绍与指南。所有账户、金额、上限、比例和历史都是虚构示例，不来自任何真实用户。

截图由实际 WPF 控件渲染，保留示例标记。在仓库外建立隔离构建，仅调整示例数据与截取流程，使企业、总金额和历史末值一致；未修改发布版采集实现，未读取真实会话，未写入真实历史。
