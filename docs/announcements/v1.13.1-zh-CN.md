# Copilot Pulse v1.13.1

大家好，

Copilot Pulse v1.13.1 更新了。这次包含上一版新增功能和最近的使用反馈修正：

- **任务计量与备注**：为一次 Bug 修复、代码审查或方案准备开始计量，等待首个成功采样后工作；结束后保留任务名、时间、观测增量和采样数。在“计量记录”回看曲线、修改备注、复制摘要，导出 CSV / JSON / PNG。
- **迷你显示任务增量**：主界面手动选择，默认仍显示月度 Overall；没有活动任务时禁用，结束后立即恢复月度显示。退出迷你保留先前的紧凑或完整模式。
- **精简用量预估**：突出预计月末累计、是否达到目标和进度条，只按 Overall 本月平均速度计算；优先读取设置的金额提醒阈值。连接诊断移到主菜单独立窗口，移除区间对比和多种速度选择。
- **采样、提醒和图表**：显示失败、重试、最近成功和缺失采样；增加提醒冷却、免打扰、静默、中断与恢复提醒。图表支持悬停、固定、缩放和框选，刷新保留缩放。可选全局快捷键、托盘操作及悬停用量。
- **统一皮肤与设置**：2×2 等大玻璃按钮、圆角图标、宽版分类设置，换肤直接进入设置的皮肤页。关于、在线更新、任务命名及计量记录同步皮肤，计量表头、输入框、滚动条和按钮统一；趋势图保持实色，优化矩阵及玻璃背景缓存。

任务增量是页面读数的观测变化，可能包含页面延迟和同期并行用量，适合观察单次任务花费，不是精确单任务账单。预估基于 UTC 配额月；时间按系统时区显示。匿名导出仍保留时间与金额。
