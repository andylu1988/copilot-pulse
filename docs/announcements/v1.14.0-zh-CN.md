主题：Copilot Pulse v1.14.0 已发布｜1.12.0 之后的全部更新

大家好，

接着上次 1.12.0 的分享，整理一下 Copilot Pulse 之后的更新。v1.14.0 现已发布，可以下载安装或在客户端在线升级。下方截图使用矩阵皮肤和虚构数据。

1.13.0：新增任务备注与计量记录，保存时间、增量和采样次数；可以回看采样健康、复制摘要、导出 CSV / JSON / PNG。还加入用量预估、提醒冷却与免打扰、快捷键、托盘悬停用量、图表缩放与提示，以及分类设置和皮肤整合。

1.13.1：在上一版基础上统一界面与名称，修复迷你任务状态；预估简化为 Overall 本月平均速度，优先读取设置的金额提醒阈值，突出月末累计和目标风险。区间对比、速度切换已移除，连接诊断改为三点菜单中的独立窗口；关于、更新等窗口统一皮肤。

1.14.0：围绕观察一次任务的花费，新增结束后的延迟结算（等待 3 次成功采样，最多 10 分钟，也可立即结束）、常用任务模板、再次计量和任务时间线标记。迷你模式支持独立选择主副指标，不开启任务也能同时看本月累计和今天 / 七天增量。月记录与可点击每日热力图整合到用量预估，每天的金额与采样数都能查看，月度卡片可复制分享。

另外加入手动隐藏金额、贴边收纳 / 全屏隐藏、桌面锁定 / 鼠标穿透、增长脉冲和更新说明卡；任务与桌面设置集中到设置页。每个新选项都可以按使用习惯调整。

使用时，任务开始前先等待首个成功采样，再开始工作，结束后让源页面读数更新。它适合观察一次 Bug 修复、代码审查、生成图片或准备方案期间的增量，但源页面延迟和同期并行用量仍可能计入，因此不是精确单任务账单。每日观测增量也不会补造缺失采样。

正式版项目与下载：https://github.com/andylu1988/copilot-pulse

下载与版本介绍：https://github.com/andylu1988/copilot-pulse/releases/tag/v1.14.0

客户端：三点菜单 → 在线更新 → 更新并重启。历史、任务、设置与登录资料保留，无需重启 Windows。欢迎反馈实际使用体验。
