Subject: Copilot Pulse v1.13.0: task usage observations, forecasts and refreshed Settings

Hi everyone,

Copilot Pulse v1.13.0 adds:

• Named task measurements: wait for the first successful sample, run a task, then finish and save its name, timestamps, observed delta and samples. Useful for observing a bug fix, code review or proposal preparation.
• An explicit main-panel option to show the current task delta in mini mode; monthly total remains the default.
• Side-by-side task comparison, PNG reports, anonymous CSV / JSON exports and copyable summaries.
• Forecasts highlighting projected month-end usage and depletion risk, with one-hour, 24-hour or current-month rates and localized UTC reset times.
• Sampling health, connection diagnostics, persistent notification cooldowns, quiet hours, silent mode, reset reminders and interruption / recovery alerts.
• Interactive chart hover, pinning, zoom and range selection, optional global shortcuts, tray actions and usage on tray hover.
• Four equal glass buttons, a crisp rounded icon, wider categorized Settings with an integrated skin gallery, fixed Close / Done actions and improved Matrix window-switch rendering.

Task deltas are observed source-page changes, not exact per-task bills; source latency and concurrent work affect attribution. Forecasts are estimates. Anonymous exports still include times and amounts, so review before sharing.
