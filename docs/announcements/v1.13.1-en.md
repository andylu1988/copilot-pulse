# Copilot Pulse v1.13.1

Hi everyone,

Copilot Pulse v1.13.1 combines the previous release's additions with the latest usability fixes:

- **Named task measurements**: observe usage during a bug fix, code review or proposal. Wait for the first valid sample before starting work, then end and save. Measurement history retains names, times, deltas and sample counts, with charts, renaming, summary copy and CSV / JSON / PNG export.
- **Optional mini task delta**: select it manually on the main panel. It is disabled without an active task; ending the task restores monthly Overall usage. Leaving mini restores your previous compact or full layout.
- **Simpler usage forecast**: projected month-end usage, target status and progress use Overall's average pace across the UTC quota month. Your configured amount alert threshold takes priority. Connection diagnostics is now a separate main-menu window; task comparison and rate selectors have been removed.
- **Sampling, alerts and charts**: inspect retries, failures, last success and missing samples. Alerts support cooldowns, quiet hours, silent mode and interruption/recovery notices. Charts support hover, pinned values, zoom and range selection, preserving zoom on refresh. Optional global shortcuts and tray actions include usage tooltips.
- **Consistent skin and settings**: equal glass buttons, rounded icons, wider categorized settings and an integrated skin page. About, Updates, task naming and Measurement history share the selected skin, including table headers, inputs, buttons and scrollbars. Charts retain solid backgrounds; Matrix rendering and glass backdrop caching have been optimized.

Task deltas reflect observed source readings, including source delay and concurrent usage, rather than exact task billing. Forecasts follow the UTC quota month; displayed times follow Windows. Anonymous exports still contain timestamps and amounts.
