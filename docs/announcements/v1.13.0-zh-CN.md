主题：Copilot Pulse v1.13.0 更新：单次任务用量观察、预估与全新设置

大家好，

Copilot Pulse v1.13.0 已更新。这次主要改进：

• 单次任务用量观察：开始时写任务备注，等待第一个成功采样后运行任务，结束并保存。记录包含名称、时间、增量和采样次数，适合观察一次 Bug 修复、代码审查或方案准备期间的花费；支持回看、重命名和复制摘要。
• 迷你数字可手动切换为当前任务增量，默认仍为本月累计；退出迷你恢复之前的紧凑或完整模式。
• 两个任务并排对比增量、时长和单次最大变化，支持 PNG 报告及匿名 CSV / JSON 导出。
• 用量预估优先展示预计月末累计量与是否会耗尽，再展示进度和采样依据；支持近一小时、24 小时和本月速度，UTC 重置按本机时区显示。
• 采样健康和连接诊断帮助识别数据延迟、失败及缺失；提醒支持冷却、免打扰、静默、重置前提醒、中断与恢复通知。
• 图表增加悬停、固定提示、滚轮缩放和框选；新增可选全局快捷键和托盘快捷操作，托盘悬停可看用量。
• 界面改为四个等大毛玻璃按钮，设置采用宽版分类布局，换肤合并到设置；关闭和完成操作固定显示，图标统一圆角。矩阵渲染也优化了窗口切换等待。

任务增量是源页面读数的观测变化，可能包含页面延迟和并行用量，不是精确任务账单；预估也不代表实际结算。匿名导出仍包含时间和金额，分享前请检查。
