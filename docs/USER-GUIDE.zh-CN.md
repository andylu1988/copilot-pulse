# Copilot Pulse 使用指南

适用版本：**1.13.1** · [项目介绍与中英文截图](../README.md) · [下载](https://github.com/andylu1988/copilot-pulse/releases/latest)

## 安装和连接

1. 下载 `CopilotPulse-Setup-1.13.1-x64.exe`，运行向导。默认按当前用户安装，不分发任何账户信息。
2. 启动后点击“连接 Microsoft 账户”，在官方页面选择自己的公司账号，按组织要求完成验证。
3. 等待 Consumption 页面加载和成功采样。应用尝试 Windows 主账户 SSO，但不保证复用系统浏览器会话或 PRT；必须具有源站访问权限。
4. 首次连接或遇到数据不刷新时，打开菜单“连接诊断”。检查时区、浏览器会话、登录、采样与本机存储；“立即采样”请求刷新源数据，“刷新”重新读取诊断状态。

![首次连接操作](screenshots/onboarding.png)

上图中间栏是登录流程说明，并非实际身份验证页。请在 Microsoft 官方登录窗口自行完成验证。

## 主界面与模式

完整模式显示企业明细，紧凑模式保留金额、趋势与四个快捷按钮，迷你模式突出一个数字。迷你退出时恢复之前的紧凑或完整模式。托盘悬停显示用量，右键可以开始 / 结束任务、刷新、暂停采样和退出。拖动空白与边缘区域移动窗口；多显示器位置会保存并检查是否仍可见。

![紧凑面板，虚构示例](screenshots/v1.13.1/release-compact-zh-CN.png)

四个主按钮是“开始任务计量 / 结束并保存”“计量记录”“迷你显示任务增量”和“用量预估”。迷你显示任务增量默认关闭，需手动选择；它改变迷你数字的含义，不会自动开启。未开始任务时按钮禁用，结束计量后立即恢复月度 Overall。

## 记录单次任务期间的增量

点击“开始任务计量”输入任务备注，**先等待首个成功采样建立零基线，再开始工作**。任务结束后等待页面用量更新，结束并保存。点击记录卡片看独立曲线，在计量记录中回看、重命名、复制摘要、导出 CSV / JSON / PNG。

![计量记录](screenshots/v1.13.1/release-tasks-zh-CN.png)

可以用它观察一次 Bug 修复、方案准备或代码审查的花费，但源页面可能延迟，同时进行的其他工作也会计入；不能视为精确任务账单。无数据显示 `—`，缺失采样不补造。有效采样数、失败与重试、估计缺失数和最近成功时间帮助判断观测质量。详见 [任务计量指南](task-measurements.md)。

## 历史趋势与时间口径

“今天”为 Windows 本机日期 00:00 到现在。“24 小时”和“7 天”为滚动时间范围。“本月”和已有月份遵循 UTC 配额月边界。UTC 月初 00:00 会换算为系统时区显示，例如 UTC+8 对应月初 08:00。图表累计金额与选中范围的净增长含义不同：净增长只计可比较有效读数的变化，不会把缺失起点假定为零。

支持总量与单个企业、累计折线与单次变化。悬停读值，单击固定提示；滚轮按光标缩放，拖动框选；双击 / 右键恢复。刷新保留缩放，切换区间会重置。异常变化标记只是提示，并不自动证明源数据错误。

![交互历史](screenshots/v1.13.1/release-hover-zh-CN.png)

## 用量预估

窗口依次突出 **预计月末累计量 → 按此速度是否会达到目标 → 进度条 → 小字统计依据**。只看 Overall，不再分账户、选择不同速度或读取历史文件；移除了区间对比及连接操作。诊断改为主界面 **⋯ → 连接诊断** 的独立窗口。

计算：**本月累计 ÷ UTC 配额月已过时长 × 当月总时长**。配置金额提醒阈值时，优先按该阈值判断是否预计超出；例如 $2,000。提醒阈值是个人目标，不会改变源站配额，因此界面明确称“达到提醒阈值”。没有金额阈值时，仅在源站提供可合计的完整数值上限时判断配额耗尽；百分比阈值缺少金额上限时会说明无法换算。静音通知不会清除预估目标。

![forecast · Matrix](screenshots/v1.13.1/release-forecast-zh-CN.png)

源读数过旧、属于上月或未来时暂停预估；按源读数时间计算，重绘不会推迟预计达到目标的时间。预估会随后续工作强度变化，仅供参考。


## 阈值、警告和提醒

设置金额阈值后主界面持续显示进度；未设置金额阈值时可显示账户配额比例。阈值是提醒线，不是服务配额。$1,234.56 对 $2,000 是 61.73%；对 $1,000 是 123.46%，超出 $234.56。

![应用内阈值警告](screenshots/v1.13.1/release-warning-zh-CN.png)

![Windows 通知示意，来自早期版本](screenshots/usage-warning-notification.png)

在设置中配置告警开关与阈值；通知页支持提醒频率、完全静默、按本机时间的免打扰、重置前提醒、采样中断和恢复提醒。冷却跨重启保存；免打扰开始结束相同时全天静音；主动暂停不触发中断提醒。系统通知受 Windows 设置影响，静音不隐藏主界面警告。

## 分类设置与皮肤

菜单“设置”打开宽版分类窗口，关闭与完成操作固定显示。“换肤”直接定位同一窗口的皮肤页。可设置中文 / English、刷新周期、数字字体、皮肤、动画强度 / 帧率、自定义背景、阈值和提醒。历史与记录图表窗口保持实色背景，方便阅读。

![皮肤设置](screenshots/v1.13.1/release-skins-zh-CN.png)

全局快捷键默认关闭，开启后：Ctrl+Alt+T 开始 / 结束任务，Ctrl+Alt+M 迷你，Ctrl+Alt+R 刷新，Ctrl+Alt+H 最近任务。冲突会提示并在诊断中显示。

## 更新、数据与分享

每小时检查公开 GitHub 正式版本，“迷你”左边显示新版本按钮。手动更新会下载、SHA-256 校验、安装并重启客户端；无需重启 Windows。提醒未打开满 48 小时自动更新，打开提醒取消该次无人值守倒计时。“关于”显示本地和云端版本。安装包目前没有发布者签名，请核对发布来源与校验值。

默认数据目录为 `%USERPROFILE%\Documents\Codex\CopilotPulse-data`。`preferences.json` 保存设置，`tasks.json` 保存任务，`history/yyyy-MM.jsonl` 保存成功读数，`sampling/yyyy-MM.jsonl` 保存采样事件，`reminders.json` 保存提醒状态。旧 AppData 数据会迁移。升级和卸载保留数据；文件未加密。备份前正常退出再复制整个目录。

匿名 CSV / JSON 和任务图片移除账户与任务名，但仍含时间、金额和任务 ID。匿名诊断只保留版本、时区与诊断状态，不含账号、金额、令牌、Cookie、完整 URL 或网页正文。分享前检查导出内容。

本版截图均使用隔离虚构数据，“示例 / 只读演示”仅标识截图环境，正式菜单不提供演示入口。源站权限、源数据延迟和组织登录要求仍然适用。
